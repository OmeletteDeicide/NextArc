# Fiche App Store — textes NextArc 2.0.1 (FR, EN, ES)

À coller dans App Store Connect.
- **Nom et sous-titre** : Distribution → **Informations sur l'app**, localisation par localisation.
- **Autres textes** : Distribution → **page de version 2.0.1**.
- **Langues** : ajoute l'anglais et l'espagnol avec le menu de langue en haut à droite de la page (« Français » → Ajouter une langue).

Limites Apple :
- nom : 30 caractères ;
- sous-titre : 30 ;
- mots-clés : 100, séparés par des virgules sans espace ;
- texte promotionnel : 170 ;
- description : 4 000.

La recherche App Store ne lit **que le nom, le sous-titre et les mots-clés**, pas la description. Un mot déjà présent dans le nom ou le sous-titre ne sert à rien dans les mots-clés : ils sont complémentaires.

## À ne pas faire (refus fréquents)
- Pas de nom d'une autre app ou marque dans les mots-clés (AniList, MyAnimeList, Crunchyroll…) : règle 2.3.7.
- Pas de « Android » ni de « Google Play » dans les textes ou les captures : règle 2.3.10.
- Pas de promesse de streaming : NextArc ne diffuse aucun épisode.
- Pas d'émojis : App Store Connect les refuse dans les textes.
- Pas de prix ni de « gratuit pour une durée limitée ». « Gratuit, sans pub » est acceptable parce que c'est vrai.
